B.I.T.T.A.

2026

Currently I'm experimenting with a project using BLE beacons to interface with an ESP32 microcontroller and other peripheral components with a goal to make a proximity-triggered user detection system. I was able to transmit WAV files from the other ESP32 to an old Bluetooth speaker I had lying around using the ESP32-A2DP library. This project also integrates the Kokoro API by making TTS requests to an AI-powered local server running on Python. Door opening events are detected with a simple IR sensor. With these put together, different users can be equipped with unique BLE tag identifiers and get tailored greetings from the speaker once they walk through the front door.
