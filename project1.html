RISC-V Processor

2025

The goal of this project was to design and create a RISC-V processor in VHDL. Hardware-scheduled pipeline and software-scheduled pipeline schematics are shown above. A single-cycle design was also created to compare performances between processor structures.In this project I designed the schematics, determined optimizations best fit for the requirements, wrote component and test code, and analyzed final timing results. I verified correct operation through simulation with a custom testbench, ensuring that instruction execution, register transfers, and memory interactions behaved as expected across pipeline stages.
