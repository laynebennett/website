Part-Finder AI Agent

2026

The goal of this project was to experiment with agentic AI applications and to apply it to a relevant problem in my engineering career. I decided upon making a web app that takes a user input describing a project they want to build and to have the agent find the best-suited electronic parts for the task. To create this application, I conducted research on the best fit models and public APIs, determined an agent workflow, and wrote and debugged code to format the agent's findings.
